# 高嶺のなでしこ 非公式スケジュール

高嶺のなでしこ（たかねこ）の出演・イベント予定を公式サイトなどから集め、メンバー別のスケジュール一覧を作るツールと、その出力データです。

> 非公式のファンメイドのデータです。内容は取得時点のもので、予定は急に変更されることがあります。参加前には必ず公式サイト・公式 X をご確認ください。

## ファイル

| ファイル | 内容 |
|---|---|
| [`schedule.md`](schedule.md) | メンバー別・日付順のスケジュール一覧（読む用） |
| [`schedule.csv`](schedule.csv) | 同じ内容の CSV（加工用、UTF-8 BOM 付き） |
| [`schedule.ics`](schedule.ics) | カレンダーアプリ用の iCalendar ファイル |
| [`fetch_schedule.py`](fetch_schedule.py) | 上記 3 ファイルを生成するスクリプト |

## 取得元

1. **公式サイトのカレンダー**（https://takanenonadeshiko.jp/schedule/ ）
   各イベントの詳細ページから時間・会場・出演メンバーを読み取ります。
2. **公式サイトのお知らせ記事**（https://takanenonadeshiko.jp/news/ ）
   カレンダーに未掲載で、記事にだけ書かれている予定を補います。
3. **Eventernote**（非公式）
   公式 X などで告知され、公式サイトにまだ載っていない出演情報を補います。

同じ予定が複数の取得元にある場合は 1 件にまとめます（カレンダーの情報を優先）。

## 使い方

Python 3.10 以上で、標準ライブラリだけで動きます。

```sh
python fetch_schedule.py                       # 今日から1年先までの予定を取得
python fetch_schedule.py --start 2026-09-01    # 開始日を指定
```

| オプション | 説明 |
|---|---|
| `--start YYYY-MM-DD` | 開始日（既定: 今日） |
| `--end YYYY-MM-DD` | 終了日。この日は含まない（既定: 今日から366日後） |
| `--no-detail` | 詳細ページを取得しない（速いが、時間・会場が空になる） |
| `--post-days N` | 何日前までのお知らせ記事を確認するか（既定: 365） |
| `--md PATH` / `--csv PATH` / `--ics PATH` | 出力先（既定: `schedule.md` / `schedule.csv` / `schedule.ics`） |
| `--force` | 予定が大きく減っていても出力する（下の「安全策」のチェックを飛ばす） |

### 安全策

取得に失敗して予定を消したまま出力しないよう、書き出す前に前回の `schedule.csv` と比べ、次の場合はファイルを書き換えずにエラーで終了します。

- 公式カレンダーから 1 件も取得できなかった
- 前回あった対象期間内の予定のうち、30% 以上（かつ 5 件以上）が見つからない（Eventernote の予定は比較しない）

見つからない予定の一覧が表示されます。本当に中止・削除された場合や期間を変えた場合は `--force` を付けて実行してください。

### 過去の予定と「済」フラグ

開始日より前の予定は、前回出力した `schedule.csv` から引き継ぎます。終わった予定は削除せず、`done` 列に「済」（`schedule.md` では ✅）を付けます。当日の予定にはまだ付きません。

`schedule.csv` を削除・リネームすると過去の予定は引き継がれないので注意してください。

## カレンダー（Mac / iPhone）に登録する

`schedule.ics` を URL で「照会（購読）」すると、個人の予定とは別の「高嶺のなでしこ」カレンダーとして表示され、更新も自動で反映されます（重複登録は起きません）。

1. Mac のカレンダーアプリで **ファイル → 新規カレンダー照会** を選ぶ
2. 次の URL を入力して「照会」

   ```
   https://takaneko-fan.github.io/schedule/schedule.ics
   ```

3. 名前・色を設定し、**場所を「iCloud」** にすると iPhone にも同期されます。**自動更新** は「1 時間ごと」〜「1 日ごと」がおすすめです。

照会をやめるときは、サイドバーのカレンダーを右クリック →「照会を解除」。個人の予定には影響しません。

### 予定の変換ルール

| 元データ | カレンダー上の予定 |
|---|---|
| 開演（または開場）時刻あり | 開演から。終了時刻がなければ **2 時間** |
| 部制の時間（`time_note`） | 最初の部の開始 〜 最後の部の終了（終了不明なら最後の部の開始 + 2 時間） |
| 時刻なし（誕生日・時間未発表） | 終日の予定 |
| 個別メンバーの出演 | タイトル先頭に【城月・松本】のように姓を付ける（タイトルに既に含まれる場合は付けない） |
| Eventernote（非公式） | タイトル末尾に「（非公式）」、ステータスは「仮」 |

開場時刻や部ごとの詳細、出演メンバー、情報元 URL はメモ欄に入ります。時刻は日本時間（Asia/Tokyo）で、予定は「空き時間」扱いなので個人の予定の空き状況には影響しません。

## CSV の列

| 列 | 内容 |
|---|---|
| `done` | 終了済みなら「済」 |
| `date` / `weekday` | 日付（YYYY-MM-DD）と曜日 |
| `open` / `start` / `end` | 開場・開演・終了時刻（記載があるもののみ） |
| `time_note` | 部制イベントの時間（例: `1部 12:30 START ／ 2部 16:00 START`） |
| `title` | イベント名 |
| `category` | カテゴリ（ライブ／イベント、メディア、誕生日、その他、お知らせ記事、Eventernote（非公式）） |
| `members` | 出演メンバー。個別メンバーの記載がなければ「グループ（全員）」 |
| `venue` | 会場 |
| `url` | 情報元のページ |
